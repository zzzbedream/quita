The solution

Same product. Auditable in real time.

Quita is infrastructure a lender puts underneath a credit life book. The insured balance, the reserves, the premium and the claims all become on-chain state that moves only when something was cryptographically proved. 

// CapitalPool.sol — the entire commercial argument
function lossRatioWad() external view returns (uint256) {
    if (totalPremiumsCollected == 0) return 0;
    return totalClaimsPaid.wdiv(totalPremiumsCollected);
}

Both counters are moved by verified events. Neither can be asserted by an operator.

The slide that matters

Verified vs trusted

FactStatusMechanism
Loan exists, principal, repaymentsVERIFIEDMerkle inclusion via 0xFD2
Outstanding balanceVERIFIEDCopied from the proved log
Premium collected, claims paidVERIFIEDCounters moved only by proofs
Transaction succeededVERIFIEDreceiptStatus == 1
Log came from our contractVERIFIEDEmitter pinned, immutable
Payout amountVERIFIEDmin(sumInsured, verified outstanding)
The borrower actually diedTRUSTED2-of-3 threshold + challenge window
Death is a fact about the world. No protocol can verify it. Anyone claiming to have oracle-ised mortality is describing a trusted attestor with extra steps.

Attestcoin integration depth

Four events verified. Three attacks closed.

Verified events

LoanDisbursedLoanMirror
RepaymentMadeLoanMirror
PremiumPaidPolicyRegistry
DeathAttestedClaimEngine

PremiumPaid is verified because it is the denominator of the loss ratio.

Attacks closed

  • Reverted tx. Inclusion ≠ success. Emit, revert, prove, collect — unless receiptStatus is checked.
  • Clone. Event signatures are unowned. Pin the emitter or anyone mints claims.
  • Cross-chain confusion. ASCBase never passes chainKey to the handler. We added a guarded entrypoint and made the inherited one inert.

Honesty

Declared limitations & roadmap

What we are not claiming

  • Death attestation is trusted. Threshold and challenge window mitigate; they do not eliminate.
  • The stablecoin is a mock.
  • Mortality table is a declared placeholder, pending BR-EMS 2021 from SUSEP.
  • We are not the insurer. Infrastructure, not a carrier.

Roadmap

  • Attestor bonds and slashing
  • BR-EMS 2021 with SUSEP filing
  • Batch verification (10 proofs / call)
  • Writability: mark loans extinguished back on Ethereum, once it leaves audit
  • Full ERC-4626 vault · disability cover · mainnet
A limitation you declare is worth more than the same limitation someone else finds.
